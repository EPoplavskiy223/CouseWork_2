# Курсовая работа 
## Проект создан для поиска и фильтрации вакансий с hh.ru
### Преимущества:
1. Легкий поиск вакансий.
2. Интуитивно понятное меню.
3. Примерный расчет гарантированной зарплаты.

## Функциональности:

### Поиск и сбор вакансий
* Поиск вакансий по ключевым словам через API HeadHunter
* Автоматическая обработка и валидация данных
* Поддержка различных форматов зарплаты (от/до/средняя)

### Система хранения
* Сохранение вакансий в JSON-файл
* Автоматическое предотвращение дубликатов
* Гибкая система фильтрации по критериям

### Анализ данных
* Топ-N вакансий по зарплате
* Поиск по ключевым словам в описании
* Сравнение вакансий по уровню зарплаты

### Удобный интерфейс
* Интуитивное консольное меню
* Человеко читаемый формат вывода
* Обработка ошибок ввода
* Легкий запуск из [main.py](main.py)
